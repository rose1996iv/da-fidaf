# Code of Conduct

## Research Integrity and Collaboration Standards

Participants collaborating on the **DA-FIDAF** research repository commit to maintaining a respectful, transparent, and scientifically rigorous environment:

1. **Respectful Communication:** Engage constructively in code reviews, methodological critiques, and experimental audits. Critique ideas, code, and empirical evidence rather than individuals.
2. **Scientific Honesty:** Report negative findings, statistical caveats, false-alarm regressions, and scope limitations transparently. Never fabricate data, conceal failed runs, or overstate unverified claims.
3. **Attribution and Confidentiality:** Respect intellectual property, dataset licensing terms, supervisor/institutional review boundaries, and the private status of pre-publication research artifacts.
4. **Responsible Security Conduct:** Use intrusion detection datasets, attack simulators, and poisoning experiments strictly for defensive research within controlled offline environments.

Concerns or conduct questions should be raised directly with the repository owner once private repository governance contacts are finalized.
